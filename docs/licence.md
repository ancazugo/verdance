# Licence and data

verdance is released under the [MIT licence](https://github.com/sdgresearch/verdance/blob/master/LICENSE). The data it downloads keeps its own licence — notably GlobalBuildingAtlas heights (`gba`) are CC BY-NC 4.0 and FABDEM terrain is CC BY-NC-SA 4.0, both non-commercial only; every source's licence is listed under [data sources](data-sources.md). The bundled map viewer includes [MapLibre GL JS](https://maplibre.org/) (BSD-3-Clause).
