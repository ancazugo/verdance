# verdance Documentation Site and 0.4.0 Release — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a MkDocs Material documentation site for verdance, themed from the new logo set, with config and API references generated from the source, and prepare the 0.4.0 release.

**Architecture:** The 478-line README splits into ten topic pages under `docs/`, plus a six-page API section generated by `mkdocstrings` from docstrings that already exist. The config reference generates from `VerdanceConfig` after its `#` field comments are converted to attribute docstrings. The docs build uses Griffe's static analysis and `uv --only-group docs`, so it never installs PySpark, GDAL or Java. Deployment is `mkdocs gh-deploy` from a GitHub Actions workflow.

**Tech Stack:** MkDocs ≥1.6, mkdocs-material, mkdocstrings[python] (Griffe), uv, GitHub Actions, hatchling.

**Spec:** [`docs/superpowers/specs/2026-11-16-docs-site-and-0.4.0-design.md`](../specs/2026-11-16-docs-site-and-0.4.0-design.md)

## Global Constraints

- **No behaviour change.** `src/` is touched only for docstrings, comment-to-docstring conversion, and the version string. No logic, signatures, defaults or field order change.
- **Docs build installs no heavy deps.** Every uv invocation for docs uses `--only-group docs`, never a bare `uv run` or `--group docs`. A docs build that pulls in `gdal==3.10.0` or pyspark is a failed task.
- **`mkdocs build --strict` is the gate.** Warnings are errors. Every task that touches `docs/` ends with a passing strict build.
- **Push to `origin` only**, never `upstream`. Changes reach `sdgresearch/verdance` by pull request.
- **Site URL is `https://sdgresearch.github.io/verdance/`** everywhere it is hard-coded.
- **Release version is `0.4.0`**, set only at `src/verdance/__init__.py:12`.
- **Docstring style is `google`**, prose-only; no `Args:`/`Returns:` sections are to be invented for existing functions.
- **Caches and temp files go under `/scratch/acz25` or the session scratchpad**, never `/home` or the repo.

## Review Focus

Failure modes the spec implies that no task's main deliverable exercises. Each has a test added to the task that owns the code.

1. **A `<picture>` element in the README breaks the PyPI front page.** PyPI's Markdown renderer allows only a subset of HTML; `<picture>` and `prefers-color-scheme` are not in it, so the dark/light logo header can render as nothing at all on the package's most-visited page. Pinned in Task 6.
2. **Griffe cannot resolve the names in `__all__`.** `src/verdance/__init__.py:14` lists `run`, `load_config`, `VerdanceConfig`, none of which exist statically (they come from `__getattr__`). Under `--strict` an unresolved-name warning fails the build. Pinned in Task 4.
3. **`exclude_docs` silently not applying publishes these design documents.** `docs/superpowers/` holds internal specs and plans; if the key is misspelled or MkDocs is below 1.6 the site ships them publicly. Pinned in Task 1.
4. **The dark-mode logo renders twice, or not at all.** Material's `#only-light`/`#only-dark` suffixes need `attr_list` enabled; without it both images show in both schemes. Pinned in Task 5.
5. **CI deploys with a different dependency set than the local build.** A local build inside an environment that already has verdance installed can resolve `paths: ["src"]` by accident; the clean runner cannot. Pinned in Task 7.

```python
# tests/test_docstring_coverage.py
import ast
import pathlib

import pytest

RENDERED = [
    "config/schema.py", "config/loader.py", "t3.py", "t30.py", "t30_buildings.py",
    "t300.py", "tree_count.py", "merge.py", "pipeline.py", "osm.py", "overture.py",
    "terrain.py", "open_buildings.py", "api.py",
]


def _public(tree):
    return [
        n for n in tree.body
        if isinstance(n, (ast.FunctionDef, ast.ClassDef)) and not n.name.startswith("_")
    ]


@pytest.mark.parametrize("rel", RENDERED)
def test_public_objects_have_docstrings(rel):
    path = pathlib.Path("src/verdance") / rel
    tree = ast.parse(path.read_text())
    missing = [n.name for n in _public(tree) if not ast.get_docstring(n)]
    assert missing == [], f"{rel}: undocumented public objects {missing}"


def test_verdance_config_fields_have_attribute_docstrings():
    """Every VerdanceConfig field carries a string literal directly beneath it."""
    tree = ast.parse(pathlib.Path("src/verdance/config/schema.py").read_text())
    cls = next(n for n in tree.body if isinstance(n, ast.ClassDef) and n.name == "VerdanceConfig")
    undocumented = []
    for i, node in enumerate(cls.body):
        if not isinstance(node, ast.AnnAssign) or not isinstance(node.target, ast.Name):
            continue
        nxt = cls.body[i + 1] if i + 1 < len(cls.body) else None
        documented = (
            isinstance(nxt, ast.Expr)
            and isinstance(nxt.value, ast.Constant)
            and isinstance(nxt.value.value, str)
        )
        if not documented:
            undocumented.append(node.target.id)
    assert undocumented == [], f"fields without attribute docstrings: {undocumented}"
```
